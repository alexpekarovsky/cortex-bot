# PingTools Pack

A collection of XSOAR tools for network connectivity monitoring and diagnostics.

## Contents

### Scripts
- **PingCheck** - Pings an IP address and returns latency, packet loss, and success/failure status

### Integrations
- **PingMonitor** - Long-running integration that continuously monitors hosts via ping and sends email alerts for downtime events

## Use Cases
- Network connectivity monitoring
- Host uptime tracking
- Automated downtime alerting
- Latency monitoring
